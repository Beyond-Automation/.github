# Security Policy

## Supported Versions

Beyond Automation actively supports the latest released version of each project.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use the **Security** tab in the affected repository and select **Report a vulnerability** when private vulnerability reporting is available.

Include:

- The affected repository and version
- A clear description of the issue
- Steps to reproduce the issue
- Potential impact
- Any suggested remediation

Beyond Automation will review the report and respond as soon as practical.

## Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.
