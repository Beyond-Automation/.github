# Beyond Automation

> Building practical PowerShell and AI-assisted automation for modern IT infrastructure.

## Mission

Beyond Automation develops open-source tools that help IT professionals automate repetitive work, improve infrastructure visibility, and strengthen operational reliability.

Our focus is on creating engineering-first solutions that are modular, well-documented, secure, and built for real-world enterprise environments.

## Flagship Project

# AIHAT

**AI Infrastructure Health Audit Toolkit**

AIHAT is an open-source PowerShell framework designed to assess Windows infrastructure health through reusable modules and clear reporting.

Current capabilities include:

- System Health
- Windows Update Health
- Configuration Engine
- Logging Engine
- Professional Console Dashboard
