### OffboardPilot -- Hybrid AD + M365 Offboarding Automation

OffboardPilot automates the full employee offboarding pipeline across on-premises Active Directory and Microsoft 365 in six steps, with a reconciliation report and audit trail on every run.

**[View source and documentation](https://github.com/Beyond-Automation/OffboardPilot)**

- Disables AD account and blocks Entra ID sign-in
- Revokes all active M365 sessions and OAuth tokens
- Converts mailbox to Shared, configures forwarding, removes licenses
- Removes Exchange Online and AD distribution group memberships
- Handles AD-only users with no Exchange Online mailbox
- Full color-coded reconciliation report and transcript per run

### AIHAT -- Infrastructure Health Audit Toolkit

AIHAT evaluates Windows system health, Windows Update, security, and networking while producing clear findings and local reporting.

**[Download the signed AIHAT v1.2.0 installer](https://github.com/Beyond-Automation/AIHAT-Releases/releases/tag/v1.2.0)**

- Free public Windows tool
- Digitally signed and timestamped
- Windows verified publisher: **Randall Lewis**
- Read-only assessment
- No account, telemetry, or audit-result upload
- Published SHA-256 checksum
